# Security policy

Loopback-only listener and per-run token: [README.md](README.md).

## Reporting a vulnerability

Do not open an issue. Use GitHub's private vulnerability reporting on this repository, or email <opensource@rethunk.tech>, with a description, affected paths or version, the plugin, game, and BepInEx versions, steps to reproduce, and impact.

## Supported versions

Only the latest release; fixes ship in a new release.
